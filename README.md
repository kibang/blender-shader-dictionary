# 블렌더 셰이더 사전 v2 · Blender Shader Dictionary v2

**사이트 / Site:** https://kibang.github.io/blender-shader-dictionary/

블렌더 5.3 셰이더 노드 112개와 재질 레시피 227개를, 값을 바꿔 가며 실제로 렌더한 그림 4,541장과 쉬운 설명으로 보여 주는 학습 사전이에요. 그림 아래의 **[블렌더로 복사]** 를 누르고 애드온의 **[새 재질로 붙여넣기]** 를 누르면 그 상태 그대로 블렌더에 들어가요.

A learning dictionary of 112 Blender 5.3 shader nodes and 227 material recipes, with 4,541 real renders showing what happens as the values change, plus plain explanations. Press **Copy to Blender** under any image, then **Paste as New Material** in the add-on to get that exact setup in Blender.

- 탭 / Tabs: 레시피 Recipes · 노드 Nodes · 텍스처 Textures (CC0 120 sets) · 엔진 Engines · 사진으로 찾기 Find by photo · 이머시브 Immersive · 기본·애드온 Basics & add-on
- 한국어 / English: 오른쪽 위 버튼 또는 `?lang=en`
- 애드온 / Add-on: `addon/shader_dict_paste-1.2.1-lite.zip` (Blender 4.2 – 5.3, Extensions; 1.2.0 kept) + texture packs `addon/shader_dict_textures_1..4.zip`
- 렌더 / Renders: Blender 5.3.0, Cycles (EEVEE-only recipes in EEVEE)
- 텍스처·HDRI: Poly Haven · ambientCG, CC0. 작가 목록은 각 텍스처 페이지와 CREDITS.txt.
- 이머시브 탭의 전시장 관련 내용 중 출처 번호가 없는 것은 '추정/재현 방법'이에요. Items without a source number in the Immersive tab are marked as estimates.
